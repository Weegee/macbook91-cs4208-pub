macbook91-cs4208-dkms 20261026.01-1 - RELEASE (tagged v20261026.01; Linux 7.3 supported, the LTS kernel is the default; driver behaviour changes verified at source and build level only, hardware NOT RUN, released by the maintainer's decision without the hardware gate)

What changed: the full list is in docs/CHANGELOG.md.
- Series 7.3 (tag v7.3, for the CachyOS kernel 7.3.0-4) is supported next to 6.18 (LTS) and 7.2.
  Linux 7.3 added two quirk rows for PCI subsystem 8086:7270 ("MacBookAir 7,2"), which the
  target machine carries. They select CS4208_MBA6, whose pin table marks the speaker pin
  unconnected. On a match the patched probe now sets the fixup to CS4208_GPIO0 before the
  quirk tables are consulted, on every series (local-changes.patch, docs/ROOT-CAUSE.md).
- Headphone jack: after the bring-up replay both converters' cached stream setup is dropped
  and a running stream is routed to the converter of the current jack state; a failed
  jack-callback registration is logged.
- One series list (kheaders/KERNEL-SERIES) drives dkms.conf's BUILD_EXCLUSIVE_KERNEL, a new
  pacman hook that warns about installed kernels of an unsupported series, and the verifier's
  "kernel series supported" check. A1534_ALLOW_SERIES_MISMATCH is removed.
- The package depends on linux-cachyos-lts-headers; linux-cachyos-headers is the one optional
  kernel. The card profile makes analog-stereo an output too, so a kernel that runs the stock
  codec offers a stereo sink (NOT RUN on hardware).
- Verifier, recovery archive, collector and tests: see docs/CHANGELOG.md.
- Source identity of the module: 6.18 c7580fd70025fa36 (was 2fc8b8ad2d1b2deb), 7.2
  c6661a7c92c95904 (was 3459bbf7be37223c), 7.3 6a7014b2db87a081.

Hardware: NOT RUN for 20261026.01. The maintainer decided on 2026-10-26 to release without the
hardware gate of docs/RELEASING.md section 4 and to treat it as a pointer for later. Open, not
verified: install of this package (pacman -U), the DKMS build on the target machine for the
LTS kernel and for 7.3.0-4-cachyos, macbook91-audio-verify on both kernels (speaker,
microphone, headphone hotplug with a running stream, deep suspend, the new checks "kernel
series supported" and "no mainline pin overrides"), a boot with headphones plugged in, and the
stock-codec stereo sink on 7.3 with the module removed. The fixup pin and the jack re-route
are therefore verified at source and build level only. Earlier hardware results (6.18 and 7.2
on 20261020.03 and 20261020.01) do not cover the changed code.
